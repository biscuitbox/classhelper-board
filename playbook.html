초보 가이드북

막혔을 때 여기부터 보세요. 거의 모든 문제가 아래 중 하나입니다.

준비 — 설치올리는 법AI 코드 넣는 법고치는 법안 될 때블루투스 연결AI를 쓸 때의 책임

준비 — 한 번만 설치

연수 전에 미리 해 두면 1차시가 편합니다. 인터넷이 되는 Windows 노트북 기준이고, 처음 한 번만 합니다.

1아두이노 IDE 2.x

arduino.cc/en/software에서 Windows용을 받아 설치합니다. 설치 중 드라이버를 물으면 모두 설치.

2보드 패키지

왼쪽 두 번째 아이콘(보드 매니저)에서 esp32 검색 → esp32 by Espressif Systems 3.x 설치. 10분쯤 걸립니다.

3라이브러리

왼쪽 세 번째 아이콘(라이브러리 매니저)에서 LovyanGFX 검색 → 설치.

4보드 연결

보드를 데이터용 USB-C 케이블로 꽂고, Tools → Port에 COM 번호가 생기는지 확인.

보드 매니저에 esp32가 안 보이면
  • File → Preferences → Additional boards manager URLs에 https://espressif.github.io/arduino-esp32/package_esp32_index.json 을 넣고 확인 → 다시 검색합니다.
  • 학교망에서 내려받기가 막힐 수 있습니다. 집이나 다른 네트워크에서 미리 설치해 오세요.

올리는 법

1코드 받기

워크벤치 맨 위 연수용 시작 코드 zip을 받아 바탕화면에 압축 풀기.

2열기

ClassHelper 폴더 안 ClassHelper.ino 더블클릭. 탭이 12개 열리면 정상.

3업로드

왼쪽 위 → 단추. 첫 번째는 2~4분, 두 번째부터는 1분 안팎.

4확인

아래에 Done uploading(또는 Hard resetting)이 나오면 끝. 보드 화면을 봅니다.

폴더 이름을 바꾸지 마세요.
  • 아두이노는 폴더 이름과 .ino 파일 이름이 같아야 엽니다.
  • 내 버전을 따로 두고 싶으면 폴더째 복사한 뒤, 폴더와 .ino 이름을 둘 다 같은 영문 이름으로 바꿉니다.

AI 코드 넣는 법 — 탭에 통째로 덮어쓰기

새 앱(2·3차시)은 AI가 파일 하나 전체를 줍니다. 그 파일의 탭에 통째로 바꿔 넣습니다.

1복사

제미나이 답의 코드 상자 오른쪽 위 복사 단추.

2탭 고르기

아두이노 IDE 위쪽에서 app_noise.h처럼 그 앱의 탭을 누릅니다.

3바꿔 넣기

Ctrl+A(전체 선택) → Ctrl+V(붙여넣기) → Ctrl+S(저장).

4업로드

→ 단추. 첫 화면의 그 칸이 켜졌는지 봅니다.

다른 탭에 붙이지 않았는지 꼭 보세요.
  • ClassHelper.ino나 helper.h에 잘못 붙이면 전체가 멈춥니다.
  • 그랬다면 Ctrl+Z로 되돌리거나, 시작 코드를 다시 받아 그 탭만 원래대로 붙입니다.

고치는 법 — 두 가지 방식

방식언제이렇게 말합니다
바꿀 줄만 받기파일이 길 때 (지뢰찾기 600줄)
한두 군데만 바꿀 때		"파일 전체를 다시 쓰지 말고 찾을 줄과 바꿀 줄만 알려 줘."
전체 다시 받기새 앱을 만들 때
기능을 크게 더할 때		"나머지는 그대로 두고 ○○를 더해 줘. 전체 코드를 다시 줘."

"쉬움 난이도의 지뢰를 6개로 줄여 줘. 바꿀 줄만."

"단추를 눌러도 아무 일도 안 일어나. 왜 그런지 찾아서 고쳐 줘."

"노랑 기준을 12로 바꿔 줘. 나머지는 그대로."

"이 오류를 고쳐서 전체 코드를 다시 줘: (오류 맨 위 세 줄)"

한 번에 하나씩

여러 가지를 한꺼번에 바꾸면 어디서 망가졌는지 찾기 어렵습니다. 하나 바꾸고 올려서 눌러 보고, 또 하나. 업로드가 1분이라 이게 결국 더 빠릅니다.

잘 되던 것이 망가졌다면

워크벤치의 완성 코드를 그 탭에 통째로 붙이면 다시 시작할 수 있습니다. 앱 파일 하나만 바꾸면 되도록 나뉘어 있어서, 다른 앱은 영향을 받지 않습니다.

안 될 때

Sketch too big 업로드 전

이유
한글 글꼴 때문에 코드가 약 2.2MB인데, 기본 설정은 1.2MB까지만 담습니다.
해결
Tools → Partition Scheme → Huge APP (3MB No OTA/1MB SPIFFS).

LovyanGFX.hpp: No such file 업로드 전

이유
화면 라이브러리가 설치되지 않았습니다.
해결
라이브러리 매니저에서 LovyanGFX 설치.

Port에 아무것도 없어요 연결

이유
충전 전용 케이블이거나, 보드가 업로드 대기 상태가 아닙니다.
해결
① 다른 케이블(데이터용)로 바꿉니다. ② 그래도 없으면 보드 뒷면 BOOT를 누른 채 USB를 꽂고 떼면 포트가 생깁니다.

Failed to connect / Connecting…에서 멈춤 업로드 중

이유
보드가 업로드를 받을 준비가 안 됐습니다.
해결
BOOT를 누른 채 업로드 단추를 누르고, Connecting…이 보이면 BOOT를 뗍니다. 끝나면 RESET을 한 번.

업로드는 됐는데 화면이 그대로예요 업로드 후

이유
보드가 새 프로그램으로 다시 시작하지 않았습니다.
해결
보드의 RESET 단추를 한 번 누릅니다.

빨간 오류가 잔뜩 나와요 AI 코드

이유
AI가 약속(helper.h)에 없는 이름을 쓰거나, 코드가 중간에 잘렸습니다.
해결
오류의 맨 위 세 줄을 복사해 같은 대화에 "이 오류를 고쳐서 전체 코드를 다시 줘". 두 번 해도 안 되면 워크벤치 완성 코드로 바꿉니다.

첫 화면에서 칸이 계속 회색이에요 AI 코드

이유
앱 파일 맨 끝 const App app = {…}의 마지막 값이 아직 false입니다.
해결
그 값을 true로 바꾸고 업로드. 또는 "app 의 마지막 값을 true 로 바꿔 줘".

글자가 □□로 나와요 화면

이유
한글이 없는 글꼴을 썼습니다.
해결
"한글은 fonts::efontKR_16 처럼 efontKR 글꼴만 써 줘."

화면이 거울처럼 뒤집혀 보여요 / 터치 위치가 어긋나요 화면

이유
보드마다 화면 방향이 조금 다를 수 있습니다.
해결
첫 화면 → 설정 → 하드웨어 점검에서 화면을 눌러 점이 손가락 위치에 찍히는지 봅니다. 거울처럼 보이면 config.h의 LCD_OFFSET_ROTATION을 0 → 6.

소리가 안 나요 소리

이유
스피커가 없거나, 소리 크기가 꺼져 있습니다.
해결
① 보드 스피커 단자(1.25mm 2핀)에 스피커를 꽂았는지 ② 설정 → 소리 크기 ③ 점검 화면의 효과음 듣기. 그래도 안 되면 config.h의 AMP_ON_LEVEL을 HIGH로.

소음 신호등이 꿈쩍 안 해요 마이크

이유
마이크 값이 안 들어오거나, 기준을 시끄러울 때 잡았습니다.
해결
점검 화면의 마이크: -○○ dBFS가 말할 때 커지는지 봅니다. 커지면 조용할 때 [기준]을 다시. 계속 -90이면 강사에게 알려 주세요.

노트북 목록에 내 보드가 안 보여요 블루투스

이유
보드가 이미 다른 노트북에 연결돼 있거나, 노트북 블루투스가 꺼져 있습니다.
해결
① 노트북 블루투스 켜기 ② 다른 노트북에 연결돼 있으면 그쪽에서 연결 끊기 ③ 보드 RESET 후 다시 장치 추가.

목록에 ClassHelper-01이 여러 개예요 블루투스

이유
여러 보드가 같은 이름을 쓰고 있습니다.
해결
config.h의 BT_NAME 번호를 내 번호로 바꿔 업로드한 뒤, 노트북에서 잘못 연결한 장치를 제거하고 다시 추가.

연결됐다 끊겼다 해요 / 연결은 됐는데 키가 안 가요 블루투스

이유
노트북에 예전 연결 정보가 남아 있습니다.
해결
노트북 블루투스 설정에서 그 보드를 장치 제거 → 보드 RESET → 다시 장치 추가.

점은 초록인데 PPT가 안 넘어가요 프레젠터

이유
키는 지금 앞에 있는 창으로 갑니다.
해결
슬라이드쇼 화면을 마우스로 한 번 클릭. 글자 단축키가 안 먹으면 PC의 한/영을 영문으로.

블루투스 연결 — 처음 한 번

1내 이름 정하기

config.h의 BT_NAME을 ClassHelper-07처럼 내 번호로 바꾸고 업로드 (1차시).

2노트북 설정

Windows 설정 → 블루투스 및 장치. 블루투스가 꺼져 있으면 켭니다.

3장치 추가

장치 추가 → Bluetooth → 목록에서 내 보드 이름을 누릅니다. 숫자 입력 없이 바로 연결됩니다.

4확인

프레젠터 제목줄의 점이 초록. 첫 화면 → 설정 → 하드웨어 점검에서도 "연결됨"이 보입니다.

  • 노트북은 보드를 무선 키보드·마우스로 압니다. 설치할 프로그램이 없습니다.
  • 한 번 연결하면 다음부터는 보드를 켜기만 해도 저절로 이어집니다. 다른 노트북에 쓰려면 원래 노트북에서 연결을 끊습니다.
  • 교실 데스크톱 PC에는 블루투스가 없는 경우가 많습니다. 노트북이나 블루투스 동글이 필요합니다.
  • 보드 뒷면 BOOT 단추는 프레젠터 화면에서 "다음 장"입니다. 화면을 안 보고도 넘길 수 있습니다.
  • 첫 화면 → 설정 → 켜면 바로 시작을 [발표]로 두면 전원을 켜자마자 프레젠터가 켜집니다.

AI를 쓸 때의 책임

  • 개인정보는 AI에 적지 않습니다. 학생 이름, 성적, 연락처를 프롬프트에 넣지 않습니다.
  • AI는 틀립니다. 그럴듯한 코드가 작동하지 않거나, 없는 기능을 있다고 할 때가 있습니다. 올려서 직접 눌러 봐야 압니다.
  • 책임은 사람에게 있습니다. 수업에 쓰는 기기는 교사가 확인하고 씁니다. 경고음 크기·깜빡임이 학생에게 불편하지 않은지도 봅니다.
  • 학생과 해 볼 때는 AI 서비스와 계정의 연령 기준을 먼저 확인합니다.
