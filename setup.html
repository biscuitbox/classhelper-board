사전 설치 안내문 — 복사해서 보내기

메신저·공문에 그대로 붙여넣기
[교탁 도우미 연수 — 사전 설치 안내]

연수 첫 시간에 바로 보드에 올릴 수 있도록, 아래 세 가지를 미리 설치해 와 주세요. (Windows 노트북 기준, 20~30분)

1. 아두이노 IDE 2.x
   arduino.cc/en/software 에서 Windows용을 받아 설치합니다. 드라이버 설치를 물으면 모두 '설치'.

2. 보드 패키지 — esp32 by Espressif Systems (3.x)
   아두이노 IDE 왼쪽 두 번째 아이콘(보드 매니저) → esp32 검색 → 설치. 10분쯤 걸립니다.
   (검색이 안 되면 File → Preferences → Additional boards manager URLs 에
    https://espressif.github.io/arduino-esp32/package_esp32_index.json 을 넣고 다시 검색)

3. 라이브러리 — LovyanGFX
   왼쪽 세 번째 아이콘(라이브러리 매니저) → LovyanGFX 검색 → 설치.

준비물: 블루투스가 되는 노트북, 노트북 충전기, 구글 계정(제미나이 사용). 3차시에는 수업에 쓰는 PPT 파일 하나.
보드와 케이블은 연수장에서 드립니다.
학교망에서 내려받기가 막힐 수 있으니 가능하면 집에서 설치해 주세요.

연수 전 실물 점검 — 보드로 꼭 확인

코드는 PC에서 컴파일과 화면 시뮬레이션까지 확인했지만, 아래는 실제 보드로만 확인할 수 있습니다.

  • ① 시작 코드가 올라가고 첫 화면이 뜬다Partition Scheme: Huge APP. 원래 지뢰찾기와 같은 보드 설정인지 확인.
  • ② 마이크 값이 움직인다첫 화면 → 설정 → 하드웨어 점검의 "마이크: -○○ dBFS"가 말할 때 커지는지. 계속 -90이면 코드 수정이 필요합니다.
  • ③ 소음 기준값이 교실에 맞는다수업 모드 노랑 +10 / 빨강 +18은 출발값. 실제 교실에서 [기준] 후 막대 숫자를 보고 app_noise.h 의 THRESH 조정.
  • ④ 노트북과 블루투스로 연결된다설정 → 블루투스 → 장치 추가 → ClassHelper-01. 프레젠터 점이 초록, PPT가 넘어가는지. Windows 10·11 둘 다 확인하면 좋습니다.
  • ⑤ 껐다 켜면 저절로 다시 연결된다보드 RESET 뒤 몇 초 안에 점이 초록으로 돌아오는지. 안 되면 장치 제거 후 다시 추가.
  • ⑥ 보드 여러 대를 동시에 켜도 된다번호가 다른 보드 2~3대를 켜고 각자 다른 노트북에 연결되는지. 배터리로 1시간쯤 버티는지도.
  • ⑦ PPT·구글 슬라이드 단축키Ctrl+L·Ctrl+P·Ctrl+E·Ctrl+A·E·Alt+P·Ctrl+H, 구글의 Ctrl+Shift+F5·Ctrl+F5. 쓰는 오피스 버전에서 한 번씩.

프롬프트 검증

워크벤치의 프롬프트는 AI 답이 매번 조금씩 달라서, 연수 전에 제미나이로 한 번씩 돌려 컴파일까지 확인해 두면 안심입니다.

프롬프트확인할 것
1차시 ①②③"찾을 줄"이 실제로 app_mine.h 에 있는지 (Ctrl+F)
2차시 ①컴파일 · 첫 화면 칸이 켜짐(ready=true) · Mic::stop() 이 stop() 안에
2차시 ②③Preferences 저장 · 경고음 10초 쉬기
3차시 ①컴파일 · 연결 전 안내 화면 · BOOT = 다음
3차시 ②③펜 드래그 · 타이머가 다른 탭에서도 흐름
자주 나오는 AI 실수
  • helper.h 에 없는 함수 이름을 지어냄 → "helper.h 에 있는 함수만 써 줘"
  • delay() 를 길게 써서 터치가 굳음 → "delay 대신 millis 로"
  • app 의 마지막 값을 false 로 둠 → 첫 화면 칸이 회색 그대로
